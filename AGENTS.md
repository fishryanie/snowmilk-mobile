# Snowmilk mobile

Use Expo SDK 57 to match Expo Go on the user's iPhone. Use version-pinned documentation at https://docs.expo.dev/versions/v57.0.0/. Keep the CMS folder conventions and ThemedView/ThemedText prop-based styling. Shared CMS components and themes were copied from eboost-cms-mobile. All business data comes from Snowmilk APIs; never embed MongoDB credentials in the app. No fixture/demo data in product code. Screens go in features; src/app contains routes only. Preserve drafts after failed requests.
